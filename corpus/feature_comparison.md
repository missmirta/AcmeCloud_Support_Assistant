|---------|-------|------------|

| File size limit | 100 MB | 5 GB |
| Backup retention | 30 days | 90 days |
| Point-in-time restore | No | Yes (7 days) |
| Custom retention policies | No | Yes |

## Migration Between Tiers

**Upgrading from Basic to Enterprise:**
- Immediate access to all Enterprise features
- Pro-rated billing for remaining month
- No data migration required

**Downgrading from Enterprise to Basic:**
- Must reduce storage to 100GB per user
- May lose access to advanced security features
- Data exceeding limits must be removed or archived
- See downgrade policy for details
